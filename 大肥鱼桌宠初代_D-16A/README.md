# 大肥鱼桌宠 · 初代（D-16A）

> ⚠️ **这是最早的版本，已经被 [`大肥鱼桌宠改_D-16BVM`](../大肥鱼桌宠改_D-16BVM) 取代。**
> 新用户请直接用最新版；本目录仅作**版本存档**，不会再更新。

## 这一代是什么

本项目的起点。只有两个核心玩法：

- 余额每下降 **0.01 元**：角色红闪 + 震动 + 播放打击音效，头顶飘出 `-0.01`，0.2 秒一次串成一条
- 余额上升（充值）：屏幕右侧掉下一盆米饭，**拖到角色身上**才一次性入账

还没有后来那些东西 —— 没有表情差分、没有铁盆、没有火控雷达。

## 与「原版」的关系

本目录的内容与 [`原版（Windows版）/DSH余额桌宠/`](../原版（Windows版）/DSH余额桌宠)
**完全相同**（8 个文件逐一对应，字节数一致）。留这一份是为了让"版本演进的起点"看得见。

## 怎么跑

1. 双击 **`启动DSH余额宠物.vbs`**
2. 第一次启动会让你填自己的 DeepSeek API Key（`sk-` 开头）

**运行要求**：Windows + PowerShell 5.1。建议装 Node.js —— 取余额会先试 .NET，
失败再走 Node，有些机器上只有 Node 这条路能通。
