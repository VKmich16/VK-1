# Mac 社区补充版 v1.4.3

感谢 VKmich16 和已有 macOS、社区版本的贡献者！我很喜欢这个小项目，在日常使用中借助 **DSH 和 Codex** 为 Mac 版补充了 Windows 新版中的一些玩法，并修复了使用中遇到的问题，希望能分享给作者和其他 Mac 用户。

## 主要改动

- 补上米饭盆喂食、铁盆拖动与叠盆、取盆、火控雷达和五帧悬停划动摸头。
- 盆和角色按 macOS 工作区对齐，避免被 Dock 挡住；修复回左下角及空闲自动回位。
- 顶盆按真实弧形盆沿遮挡头发，修复空隙、侧发截断和取盆时头发突然出现。
- 补齐其他三个角色的紧张、冷淡、平静表情；新增左右朝向、独立音量、音频导入及演示设置。
- 限制道具窗口和网络响应大小，修复余额暂存、极端数值和对象释放问题；使用单个 30 Hz 主循环。

## Mac 操作约定

- 摸头：不按鼠标，在角色不透明区域来回划动；累计 24 pt 后持续移动 0.5 秒触发。停止或离开 0.15 秒结束；按键、拖拽、回位会打断并冷却 1 秒。
- 雷达：饭盆出现即显示，首次落地后 10 秒锁定，再过 1 秒吸收。
- 原生菜单和音频文件导入替代 Windows 声音剪辑/声音库界面。新增脸部贴图由 AI 编辑参考图后制作，保留原角色身体与轮廓；详细来源随源码提供。
