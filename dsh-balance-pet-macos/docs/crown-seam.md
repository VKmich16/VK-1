# 1.4.3 顶盆接缝修复

上一版按贯穿角色右半边的倾斜直线裁头顶，而饭盆 PNG 的下沿实际为弧线，两者之间产生空白，盆两侧头发也会被截断。

本版从饭盆原图的 alpha 通道提取实际下沿，缓存为归一化轮廓；在角色透明绘图层中，沿盆沿遮挡藏在盆里的头顶。范围限定在饭盆实际宽度内，侧发自然保留；遮挡线向盆沿内部重叠最多 1 pt，给抗锯齿边缘保留头发衬底，并加窄幅接触阴影。盆淡出时，同步恢复其后的头发，避免取盆瞬间头顶跳出。

饭盆尺寸、位置沿用 1.4.2；人物与饭盆原始图片资源沿用原图。左右镜像、四档大小、四个角色与叠盆使用同一套轮廓合成。

CrownSelfTests 使用独立解码的饭盆 alpha 边界检查实际 CGContext 输出：弧形盆沿下方头发 alpha 完整；盆外侧头发保留；遮挡区透明；半透明取盆时头发同步恢复。另生成四角色、左右朝向、单盆及叠盆预览。
