## 这一代加了什么

在[初代](../大肥鱼桌宠初代_D-16A)的基础上：

- **米饭盆的拖拽惯性** —— 扔出去的盆会滑行一段再停下，重量感出来了
- **DSH 风格右键菜单**第二版 —— 手绘矢量图标（不再用 Emoji）、分组标题、
  整行浅蓝悬停、自绘圆角蓝勾、自绘细箭头、统一 36 px 行高
- **声音子菜单** —— 开关 + 五档音量（0/25/50/75/100 %）+ 自定义，写进 `state.ini`，不影响系统音量
- **平板数字自适应** —— 余额位数变多时数字自动缩小，不再溢出屏幕

还没有的：表情差分、铁盆、火控雷达（都在 v3）。

## 怎么跑

1. 双击 **`启动DSH余额宠物.vbs`**
2. 第一次启动会让你填自己的 DeepSeek API Key（`sk-` 开头）；装了 DSH 则自动读取

**运行要求**：Windows + PowerShell 5.1。建议装 Node.js —— 取余额会先试 .NET，
失败再走 Node，有些机器上只有 Node 这条路能通。
