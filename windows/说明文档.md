# DSH 余额宠物 · 说明文档

角色举着一块纯黑屏幕的平板，屏幕上实时显示你的 DSH（DeepSeek）余额。
余额每下降 0.01 元，角色就红闪一下 + 轻微震动，同时播放一次打击音效，头顶弹出红色的 -0.01 向上飘并渐隐。

## 一、启动

1. 双击《启动DSH余额宠物.vbs》。

2. 角色出现在屏幕左下角（默认大杯 = 454×454 像素），平板上几秒后显示余额。

3. 开机自启：Win + R 输入 shell:startup，把 vbs 的快捷方式丢进去。

前提：Windows PowerShell 5.1（系统自带）+ Node.js（建议保留，理由见下）。

API Key 会自动读取 %USERPROFILE%\.dsh\.credentials.yaml 里已有的 DEEPSEEK_API_KEY；读不到时会弹出输入框让你填（分享给别人时对方就用这个入口）。

为什么建议保留 Node：取余额走两条路 —— 先试 .NET，失败再改用 Node。有些机器上 .NET 拿不到 TLS 凭据（SEC_E_NO_CREDENTIALS），这时就只剩 Node 这一条路。两条路的结果都会写进 pet.log，所以出问题时先看日志就能知道走了哪条。

## 二、操作

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动 | 只有在按住左键时才能移动；一松开就自动吸附回屏幕左下角（0.16 秒缓动） |
| 左键按住米饭盆拖动 | 把盆拖到角色身上（含头饰）就会“喂”给她：盆消失、头顶冒像素爱心、充值金额一次性入账 |
| 右键 | 菜单，见下 |
| 角色以外的透明区域 | 鼠标穿透，不挡你点桌面 / 其他窗口 |
| 双击托盘图标 | 手动触发一次扣费动画（含音效） |

右键她弹出的是一块**面包屑面板**（不是传统的层层级联菜单），里面按功能分成几块：

| 区域 | 里面有什么 |
| --- | --- |
| 演示 | 模拟扣费（1 次 / 10 次 / 自定义金额）、模拟充值（掉米饭盆）、打开火控雷达 |
| 尺寸 | 中杯 340 px / 大杯 454 px（默认）/ 超大杯 624 px / 自定义宽高 |
| 外观 | 浅色 / 深色（DSH 风格） |
| 声音 | 「开启声音」开关，以及进入设置窗口「音量」页 |
| 其他 | 设置 API Key、设置窗口（显示 / 音量 / 音效库 三页）、退出 |

设置窗口里的「音效库」可以放自己的音效，四个提示音各自独立开关与调音量。

### 充值：掉米饭盆

云端余额上升时（有人给你充了钱），程序不会直接改屏幕上的数字，而是：

1. 从屏幕右边缘丢下一盆米饭，让它自由落体 + 弹跳（弹几次取决于落下高度，最多 3 次）；

2. 屏幕数字保持不动，等待你去拿；

3. 用左键把盆拖到角色身上（碰到头发/头饰也算）→ 盆消失、头顶冒像素爱心、这笔充值一次性加到屏幕上，同时飘一个绿色的 +x.xx（和扣血的红色数字区分开）；

4. 不拖就永远不加。盆可以一直躺在屏幕底部；也可以同时有多个盆（一笔充值一个盆），它们彼此有碰撞体积、不会叠在一起，逐个拖给她就逐个入账。

看不到盆？确认是余额上升（充值）而不是下降；只在两次轮询之间“涨了又被花掉”（净额没变）是不会掉盆的，这是刻意的。

### 两种刷新的区别（重要）

- 后台自动轮询（默认每 2 秒）：余额下降时一分钱一分钱地扣，每次扣费都完整播一遍动画 + 音效。

- 右键「立即刷新余额」：立刻对齐到最新余额（不补播动画）。想看连续动画就用「演示连续扣费」。

## 三、扣费的节奏

步长固定为 0.01 元，不再可调。这是刻意的设计：

- 0.01 是接口报数的最小单位，所以永远不会有“凑不满一格的零头”，也就从根上排除了“数字动了但没播动画”这类问题。

- 每次扣费之间间隔 0.2 秒，每次都完整播放红闪 + 震动 + 音效 + 飘字。间隔短了之后，飘出的数字会像连击那样向上错开排成一条串。

### 规则：云端余额一有变化，就把差额换算成 N 个 0.01，然后一个一个地扣。

例：余额从 30.00 变成 29.95（少了 0.05）→ 连续扣 5 次：-0.01、-0.01、-0.01、-0.01、-0.01，屏幕数字 30.00 → 29.99 → 29.98 → 29.97 → 29.96 → 29.95，每一次都有完整的红闪 + 震动 + 音效 + 飘字，间隔 0.2 秒，五个 -0.01 依次向上串成一条。

### 数字绝不会在没动画的情况下变化：数字只在扣费那一帧变化，而且一次只变 0.01。

“实时”指的是延迟小：服务器那边余额一变，下一次轮询（默认 2 秒）就把它换算成扣费次数，第一次扣费当帧就会弹出，不会压着等下一轮。

大额跳变的保护：一次最多排队 40 次（0.40 元），避免云端一次性跳很多时动画播上好几分钟。剩下的部分会在后续轮询里继续补完。

## 四、表情差分：她会换脸

角色有四张脸，程序按当前状态自动切换：

四张表情，文件名固定为 sprites\expression_*.png

| 表情 | 什么时候出现 |
| --- | --- |
| 开心（张嘴笑） | 默认状态。空闲、有盆在场、刚喂完，都是这张 |
| 紧张（闭眼 + 汗） | 扣费动画播放时。扣完之后还会保持约 1 秒才收回 |
| 傲娇（波浪嘴） | 米饭盆满 10 秒还没被领取的时候 |
| 冷脸（面无表情） | 铁盆扣在她头上的时候（见第六节） |

### 优先级（从高到低，第一个命中的生效）

```
1. 铁盆在头上 且 场上没有活的米饭盆   -> 冷脸
```

```
2. 扣费动画正在播 / 刚播完的保持期     -> 紧张
```

```
3. 米饭盆满 10 秒未领取               -> 傲娇
```

```
4. 其余                               -> 开心
```

两条容易搞混的规则，这里说清楚：

- 冷脸压过紧张：铁盆扣在头上时，即使正在扣费她也保持冷脸。只有新的米饭盆掉下来才会让她重新开心起来。
- 紧张压过傲娇：盆满 10 秒变傲娇之后，如果这时发生扣费，她会先变紧张，扣完再回到傲娇（盆还在场上、还是没人喂）。

## 五、铁盆：米饭盆的「后事」

米饭盆被她吃掉的那一瞬间，会在盆消失的那个位置掉出一个铁盆。

两个盆尺寸同源，落地后走同一套物理（下落、弹跳、拖拽）

铁盆和米饭盆一样：可以拖来拖去、有弹性（Q 弹）、有惯性、会弹跳。但它有三点不同：

- 不带钱 —— 它纯粹是个道具，拖到哪都不会让余额变化
- 不能被吃 —— 你把它拖到她身上，它只会掉下去，不会消失
- 不会被火控雷达锁定 —— 名牌永远只认米饭盆（见第七节）

### 把它扣到她头上

两种方式都行：拖着铁盆放到她头上，或者把铁盆扔到她头顶让它自己落下去。

只要盆沿落到头的位置，它就会扣在她头上：

- 她的表情变成冷脸，而且这种状态下继续扣费也保持冷脸（见第五节）
- 盆会跟着她一起震、一起 Q 弹（它是贴在她身上的实物）
- 盆沿会挡住穿出来的发箍和呆毛（不然会从盆里穿模出来）

### 拿下来

双击她的头（点两下）：她会再弹一下，铁盆渐隐消失，立绘恢复正常，表情回到正常流程（开心 / 紧张 / 傲娇，看当时的状态）。

> 铁盆同时只会有一个：已经有一个在场（或扣在头上）时，吃掉下一个米饭盆不会再掉新的，免得两个盆叠在一起。

## 六、火控雷达：目标名牌

场上有米饭盆时，盆的周围会出现一个《战争雷霆》风格的目标名牌（绿色方括号 + 一排读数）：

名牌的各个部分（示意图，几何比例与程序里的实际绘制一致）

| 读数 | 含义 |
| --- | --- |
| 距离 | 盆离角色多远，单位 kpx（千像素） |
| 接近率 | 盆正在靠近还是远离：正数 = 靠近，负数 = 远离，单位 px/s |
| 相对高度 | 正数 = 盆比角色高，负数 = 比角色低，单位 px |
| 方向环 | 环上一根指针，指向盆相对角色的方位（可旋转） |

方括号的大小跟着米饭盆的大小走，盆被拖着移动时名牌也跟着走。

### 自动锁定与吸附

米饭盆落地后 10 秒还没被领取，就会发生：

1. 名牌锁定（出现方括号）。
2. 再过 1 秒，盆开始被加速吸向角色。
3. 吸到身上 → 自动走一次完整的「喂食」（加钱 + 爱心 + 音效）。

吸附是缓缓加速的（不是一把抓走），从锁定到吃掉大约 0.5 – 1.5 秒，取决于盆离得多远。

### 多个盆：一起锁定，一起吸走

不管场上有几个盆，只要有一个满 10 秒，所有的盆都会被锁定。

比如你连着充了三次，掉了三个盆：

```
第 1 个盆掉下 -> 等 2 秒 -> 第 2 个盆掉下 -> 再等 8 秒，什么都不做
```

```
^ 此时第 1 个盆已经满 10 秒
```

结果：三个盆同时出现方括号，然后一起被吸过去。刚掉下来 2 秒的那个盆不会再自己等 10 秒。

### 想手动看看名牌

右键 → 测试充值动画 → 打开火控雷达。它只是把名牌提前亮出来给你看读数，不会缩短倒计时、也不会启动吸附。自动流程照常在自己的时间点锁定并吸走。

## 七、摸头：她会回应你

不用按键，把鼠标**在她身上来回划几下**就行：

- 累积划动超过 **24 像素**、并且持续 **0.5 秒**，一只手就会从上方下来摸她的头；
- 她的手会**把她的头顶压扁**（petpet 那套形变），表情同时变成紧张；手的大小跟着当前尺寸档位缩放，中杯/大杯/超大杯比例一致；
- 停下 **0.15 秒**后手才抬起；中途按鼠标任意键会**立刻**结束，并且在这之后 **1 秒内**不再触发（防止拖拽她的时候误摸）。

**她头上扣着铁盆时**：会先把盆取下来（渐隐），等盆消失后才开始摸 —— 因为盆是贴图、摸头要竖直压扁，同时进行会把盆画错位置。等待期间把鼠标移开就会取消。

不想要这个功能：设置 →「鼠标抚摸」开关关掉，之后划动不会再触发。

## 八、峰谷副屏

双击平板切换余额 / 峰谷两种面板

双击她手里的平板，就切成峰谷查询：云端北京时间 / 梁文峰（高峰）·梁文谷（空闲）/ 距离时段倒计时。两种面板原地切换，不会叠出新窗口。

- 北京时间 00:30–08:30 空闲，其余高峰，来源：DeepSeek 官方定价页。

- 时钟必须用云端：余额接口的 HTTP 响应头 Date。

- 法定节假日 / 调休周末全天按空闲计费 —— 尚未实现（需要一份日历，不猜）。

## 十、它是怎么工作的

- 余额来源：GET https://api.deepseek.com/user/balance → balance_infos[].total_balance（CNY）。

- 两个数值：真实余额（接口刚读到的值）与屏显余额（平板上打印的数字，只在扣费那一帧变化，且一次只变 0.01）。账面基准与屏显余额成对维护，欠款 = 账面基准 − 真实余额，每次读数都重新推导，所以任何时刻到达的数据都不会让数字失同步。

- 逐分结算：欠款换算成 N 次 0.01 的扣费，一次一个、间隔 0.2 秒，每次都完整播动画 + 音效。

- 轮询与延迟：默认每 2 秒问一次。取数在后台线程做（避免卡住界面），拿到结果后当帧结算。

- “立即刷新余额”= 立即对齐：屏显直接等于真实余额（不足一格的零头也抹平），并清掉演示偏移。

- 红闪：角色贴图预处理为一张纯红剪影（保留 alpha）。叠加强度随尺寸自适应（小尺寸约 64%，大尺寸约 30%）。

- 震动：阻尼正弦抖动（约 ±8px 峰值，0.55 秒衰减），固定像素幅度而不是按比例缩放。同时生效的受伤层最多 3 个，总位移有硬上限。

- 音效：走 Win32 MCI 接口，预先开 4 个别名槽位。每次飘字弹出就找一个空闲槽位播放，互不打断、可以叠着响。

- 屏幕：黑色内屏保持原样不涂任何颜色，只画「DSH 余额」和数字（浅色字 + 深色描边），用三点映射贴合到屏幕四边形上。余额位数变多时，数字会自动缩小以留在屏幕内。

- 尺寸：中杯 / 大杯 / 超大杯 = 340 / 454 / 624 像素（正方形，1:1），「自定义」直接填像素。像素是存储单位。

- 充值：云端余额上升 → 差额记成“待领额度” + 掉一个米饭盆；只有把盆拖到角色身上才一次性入账。

- 窗口：WinForms 无边框 + 分层窗口（逐像素 alpha），WM_NCHITTEST 对透明像素返回 HTTRANSPARENT 实现穿透点击。

- 流畅度：每帧只重画“这一帧变过的那一块”，屏幕推送也走常驻缓冲区，不再整屏重建。

## 十一、分享给别人（或公开分享）

要发整个文件夹，不能只发启动程序。启动器只是个外壳，真正干活的是同目录下的 dsh_pet.ps1 + sprite.png + rice.png + hit.mp3 + feed.mp3；少一个都会缺图或缺音效。

### 如果你要转发 / 公开这一份，先删掉下面这些（它们只属于你本人）：

| 文件 | 为什么不能发 |
| --- | --- |
| apikey.txt | 里面是你的 API Key |
| pet.log / error.log | 运行日志，含你的余额数值与路径 |
| state.ini | 你调过的尺寸与音量，对方不需要继承 |
| _shot_*.png / _bowlgirl_*.png | 诊断命令截的是整个桌面，会把你的屏幕内容一并发出去 |

脚本里没有写死任何绝对路径或用户名（用的是脚本自身所在目录、%USERPROFILE%），所以对方解压到任何目录都能直接用。

对方第一次启动时会弹出输入框让他填自己的 API Key（因为他多半没装 DSH，程序找不到 .dsh\.credentials.yaml）；取消也能用，只是先离线显示 --，之后右键菜单随时补填。

## 十二、换图 / 换音效 / 改屏幕位置

### 换立绘：重新生成贴图，并打印黑屏四角坐标

powershell -ExecutionPolicy Bypass -File .\make_sprite.ps1 -Source "C:\path\to\new.png"

把打印出的四角填进 dsh_pet.ps1 里 Relayout() 的 qx / qy（1024 贴图坐标系）即可。换音效只要把新文件命名为 hit.mp3 覆盖，或设 DSHPET_SOUND_FILE。

## 十三、自检与排错

dsh_pet.ps1 --selftest   渲染一帧到 selftest.png，并打印尺寸/账本状态

dsh_pet.ps1 --shot   真实开窗跑 2.5 秒：打印抖动偏移、文字落点

dsh_pet.ps1 --simchain   喂一串模拟余额，检查“按格扣费 + 拆格补扣 + 演示不冻结”

dsh_pet.ps1 --topup   充值链路全量自检（离线）：冻结 → 掉盆 → 拖给她 → 入账

这些自检都不会改你的 state.ini（尺寸/音量不会被测试改掉）。

### 常见问题

| 现象 | 排查 |
| --- | --- |
| 角色不出现 / 一闪而过 | 用《启动（调试窗口）.cmd》，再看 error.log 与 pet.log |
| 没有声音 | 看 pet.log：正常会有 sound ready: ... volume=80；sound pool failed → 音效文件缺失或被占用；sound: nothing played → 系统 MCI 打不开该 mp3 |
| 掉了米饭盆但数字不变 | 设计如此：必须用左键把盆拖到角色身上才会入账。拖不动就看 pet.log 有没有 bowl landing: / rice grab 记录 |
| 屏幕一直显示 -- | pet.log 里 node not found → 装 Node.js 或设 DSHPET_NODE；HTTP 401 → Key 不对。屏幕角落出现红点 = 当前离线 |
| 红闪太强/太弱 | dsh_pet.ps1 里 double maxTint = Math.Max(0.30, 0.64 - _scale * 0.75); 改这两个数即可 |

## 十四、改脚本前必读

这些 .ps1 文件是故意写成纯 ASCII 的（界面上的中文用 C# \uXXXX 转义）。因为 Windows PowerShell 5.1 在没有 BOM 时按 ANSI 读取脚本，直接写中文会乱码甚至解析失败。要改脚本请只写英文，中文用 \uXXXX 转义；改说明文档这类文件请用支持 UTF-8 的编辑器。

## 十五、想微调节奏

步长固定 0.01、间隔固定 0.2 秒（刻意不可调）。真要改，只能改源码常量（在 dsh_pet.ps1 顶部附近，只写英文）：

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| StepYuan | 0.01 | 每次扣多少 |
| CueGapSec | 0.2 | 两次扣费之间的间隔 |
| MaxCuesPerPoll | 40 | 单次轮询最多排队多少次，防云端大跳变时动画播太久 |

轮询快慢用环境变量 DSHPET_POLL_MS（默认 2000 毫秒，最小 1000）。
