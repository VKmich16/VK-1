# DSH 余额宠物 · 快速开始

一个贴在桌面上的小挂件：角色举着一块黑屏平板，平板上显示 DeepSeek 余额。
余额每下降 0.01 元，角色就红闪 + 震动 + 播放打击音效，头顶飘出 -0.01。

### 怎么用

1. 解压到任意目录（路径里有中文也没关系，但请不要放在只读位置）。

2. 双击 《启动DSH余额宠物.vbs》。

3. 第一次启动会弹一个框让你填 DeepSeek API Key（sk- 开头）。填完确定即可；不想填就取消，挂件会先离线待着（屏幕显示 --）——之后随时右键 →「设置 API Key」补上。如果你已经装了 DSH，Key 会被自动读取，不弹框。

4. 挂件出现在屏幕左下角，默认大杯 = 454×454 像素。

### 常用操作

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动 | 移动；松手后自动回到屏幕左下角 |
| 左键按住米饭盆拖动 | 把盆拖到角色身上就“喂”给她：盆消失 → 头顶冒像素爱心 → 这笔充值一次性入账 |
| 右键 | 菜单：立即刷新余额 / 测试扣费 / 测试充值动画 / 演示连续扣费 / 尺寸 / 声音（开关+音量）/ 设置 Key / 退出 |
| 双击托盘图标 | 手动触发一次扣费动画 |

立即刷新余额 = 平板立刻对齐到最新余额（不补播动画）。后台每 2 秒自动查一次；余额一有变化就一分钱一分钱地扣，每次都有完整的动画 + 音效。

### 有人给你充钱时

从屏幕右侧掉下一盆米饭，拖到她身上才入账

屏幕数字先不动；把它拖到角色身上（碰到头发也算）才会加上去，同时飘一个绿色的 +3.00。不拖就永远不加——所以你想什么时候“收钱”都行。想先看效果又不花钱：右键 →「测试充值动画」→「模拟充值 3 元（掉米饭盆）」。

想看连续扣费的效果：右键 →「演示连续扣费」→ 选 -0.1 之类，就会以 0.2 秒一次连着扣 10 次给你看。

嫌吵就右键 →「声音」→ 取消「开启声音」，或把音量调到 0 %（立刻生效，会记住）。

### 遇到问题

### 双击 vbs 没反应 / 杀软报警

这个挂件用 Windows 自带的 PowerShell 写界面，.vbs 启动器只是用来隐藏黑框，偶尔会被杀软误报。改成双击《启动（调试窗口）.cmd》，它会保留一个黑窗口把错误显示出来。

### 屏幕一直显示 --

余额没取到。看同目录的 pet.log：每次请求的结果都记在里面。

- 出现 node not found → 装一个 Node.js（LTS 版即可）。程序会先试系统自带的 .NET，失败才用 Node；两者都不行就取不到余额。

- 出现 HTTP 401 → Key 不对，右键 →「设置 API Key」换一个。

### 卡顿 / 托盘图标消失

右键 →「退出」，再重新启动一次即可。

### 关于

这是一个独立的桌面小程序（不是 DSH 插件）：它自己是一个进程，只从 %USERPROFILE%\.dsh\.credentials.yaml 读取 API Key，其余和 DSH 没有任何耦合，所以 DSH 关掉它也照常运行。

### 它不联网上传任何数据，只访问 DeepSeek 官方的余额查询接口。
